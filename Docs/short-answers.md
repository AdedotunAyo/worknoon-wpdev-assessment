1. Difference between Google Knowledge Graph and Google Knowledge Panel

The Knowledge Graph is Google’s internal database that stores information about entities and how they are connected. The Knowledge Panel is the visible box shown in search results that displays information pulled from the Knowledge Graph.

2. How Google determines entity identity

Google determines entity identity by analysing consistent signals across the web, such as brand name usage, structured data (schema markup), backlinks from trusted sources, social media profiles, and repeated mentions of the same entity across authoritative platforms.

3. When to create Custom Post Types instead of pages

Custom Post Types are used when the content is structured, repeatable, and needs to be managed separately from standard pages. For example, services, portfolios, listings, or case studies. Pages are better for static content like About or Contact pages.

4. Recommended plugins for speed optimization and why

WP-Optimize is recommended because it combines caching, database cleanup, and image compression in one plugin, making it efficient and easy to manage performance from a single place. It helps reduce database bloat, improves load time, and enhances overall site speed without requiring complex configuration.
